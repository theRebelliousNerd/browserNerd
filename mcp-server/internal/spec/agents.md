# Specification Corpora

This package ingests bounded named Markdown corpora. Index files are ordering
hints; bounded root scans remain authoritative. Generic frontmatter and prose
are deliverable context. BrowserNERD bindings and invariant directives are
optional executable extensions.

Matching prioritizes file, route, component, and selector bindings, then
feature terms. Responses must remain deterministic, provenance-preserving, and
bounded by file size, file count, result count, and excerpt size.
